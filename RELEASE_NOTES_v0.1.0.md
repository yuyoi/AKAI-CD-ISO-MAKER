## Akai CD ISO Maker v0.1.0 (UNTESTED BUILD)

**Not yet tested on real sampler hardware.** Reading real Akai CDs is tested; discs written by this tool have not been loaded on an S1000 / S2000 / S3000 yet. Use at your own risk and please file a "Hardware test report" issue with the result.

- Windows exe, no Python needed: `AkaiCDISOMaker.exe` (GUI; also takes `make`, `info`, `export` on the command line).
- Make Akai CD images from wav / mp3 / flac / ogg / aiff, loop finder, auto-mapping, S1000 format (S3000 mode experimental).
- Read and edit existing Akai CDs. Export WAV, SFZ, SF2.
- Burn the .iso as an image (see README), not as a normal data disc.
